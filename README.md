Places To Visit
===============

Local setup
-----------

1) Install dependencies
   - Frontend (root): `npm install`
   - Backend: `npm --prefix backend install`

2) Run both services
   - `npm run dev:all`
   - Frontend: http://localhost:3000
   - Backend: http://localhost:3001

Environment config
------------------

Frontend reads `/runtime-config.json` to determine the backend URL.
This file is generated by `npm run build` (or by `npm run dev:all`) from
`API_BASE_URL` or `VITE_API_URL`.

Create a `.env` (see `.env.example`):

- `API_BASE_URL` - preferred runtime key (local/dev)
- `VITE_API_URL` - supported for Vercel env configuration

Deployment notes
----------------

Vercel:
- Set `API_BASE_URL` or `VITE_API_URL` to the Render backend URL.
- Ensure the build runs `npm run build` to create `runtime-config.json`.

Render (backend):
- Ensure `backend/server.js` CORS list includes your Vercel domain.
